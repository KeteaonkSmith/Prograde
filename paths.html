Goal roadmaps

Do not just collect links. Build a path you can follow.

These roadmaps show beginner-friendly sequences: learn the foundation, make proof, try a public challenge, then move toward stronger programs, scholarships, or projects.

Cybersecurity

NetAcad -> picoCTF -> CyberPatriot -> project -> summer program

Start with networking and Linux basics, practice CTF problems, join a team competition, then save proof through writeups or a small security project.

Find cyber resources
Engineering

Open course -> local build -> open house -> selective summer program

Use free coursework to learn a core skill, build something visible, visit engineering events like campus open houses, then apply when your story is concrete.

Find engineering resources
College affordability

Fee waivers -> BigFuture -> local awards -> national scholarships

Start early with planning tools and waiver eligibility, then prioritize scholarships where your background and evidence match the rubric.

Find affordability resources
Writing and humanities

Research guide -> essay practice -> competition -> portfolio

Use credible sources, write arguments with feedback, enter essay or history competitions, then keep a portfolio of finished work.

Find writing resources
Pre-med and science

Open science course -> volunteer context -> research reading -> summer program

Build foundations first, learn how research actually works, then target programs that match your grade and experience level.

Find science resources
Business and entrepreneurship

Learn basics -> pitch project -> team event -> scholarship or competition

Use free tools to make a real pitch or prototype, then choose competitions that judge evidence instead of vague ambition.
